# Prompt: Share Tab UI

Armame un plan específico para la tab Compartir del perfil del avatar.

Objetivo:
Mostrar métricas básicas arriba y lista de links compartidos abajo.

Debe incluir:

- tab Compartir en `/avatars/[avatarId]`
- cards de métricas
- lista/tabla de links
- crear nuevo link
- copiar link
- preview público
- activar/desactivar
- eliminar
- loading/error/empty states

Reglas:

- Share vive dentro del perfil del avatar
- no mezclar con Interact
- no mostrar prompts/contexto al público

Checklist:

- creador ve métricas
- creador gestiona links
- copiar link funciona
- link desactivado muestra estado claro
