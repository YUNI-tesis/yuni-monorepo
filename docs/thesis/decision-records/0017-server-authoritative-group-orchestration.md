# Orquestación grupal con respuestas redactadas por YUNI

## Estado

superseded

## Decisión

Esta variante hacía que YUNI planificara también el contenido final de cada intervención. Fue reemplazada por ADR 0018 porque aumentaba el tiempo hasta el primer audio y separaba la respuesta del conocimiento, el modelo conversacional y la voz configurados en cada Agent.
