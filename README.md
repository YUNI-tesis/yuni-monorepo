# Evidencia visual de las PRs

Esta rama no se mergea: solo guarda las capturas que muestran cada PR. Cada carpeta corresponde a una PR y, cuando aplica, separa `antes/` y `despues/`.

Las capturas se sacan con Playwright contra YUNI en local, con los datos de `packages/db/prisma/seed-tesis-demo.ts`. No se usa ninguna base ni proveedor remoto.
